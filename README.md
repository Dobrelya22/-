# Стрела Олегуса

Мод для Minecraft (Fabric 1.21.1), который добавляет волшебную «Стрелу Олегуса» по образцу стрелы Йонду из «Стражей Галактики». Стрела летает сама, плавно меняет траекторию, облетает препятствия и раз за разом пронзает мобов, оставляя за собой переливающийся радужный след.

## Возможности

- **Самостоятельный полёт.** Стрела доворачивает к цели с ограниченной угловой скоростью, поэтому траектория плавная. Пронзив цель, она пролетает насквозь и заходит на новый круг.
- **Облёт препятствий.** Если цель за стеной, стрела ищет путь по воздуху (A*, 26 направлений) и летит к самой дальней видимой точке пути. Стена впереди заставляет её отворачивать резче. Если стрела всё же застряла, через 2 секунды она ненадолго проходит сквозь блоки.
- **Два режима:**
  - *Выбранная цель* — атакует моба, на которого вы смотрите (с небольшой доводкой прицела);
  - *Все мобы* — по очереди атакует всех мобов в радиусе 50 блоков вокруг вас: сначала враждебных, затем ближайших.
- **Игроков не трогает.** Целью может быть только моб. Ваших питомцев и транспорт, на котором вы едете, стрела тоже не атакует.
- **Ускорение в толпе.** Если вокруг цели больше трёх мобов, стрела разгоняется на 25% за каждого лишнего моба, но не больше чем вдвое. Урон всегда одинаковый — 8 (4 сердца) за удар.
- **40 секунд действия.** За 5 секунд до конца звенит колокольчик. Когда время выходит, стрела прилетает к владельцу, делает несколько кругов вокруг него и падает предметом, который можно подобрать.
- **Свист.** Стрелу можно отозвать досрочно: она отвечает звоном, прекращает атаки, возвращается и сама ложится в инвентарь.
- **Надпись над полоской здоровья:** текущий режим, а пока стрела летит — её состояние, оставшиеся секунды, ускорение и число побед. Над надписью — радужная полоска оставшегося времени, в последние 5 секунд она мигает красным.

## Как выглядит

- Объёмная модель: тонкое красное древко, вытянутый наконечник с раскалённым остриём и крестовое оперение.
- Стрела светится сама: у острия переливается яркий блик, вокруг — мягкий красный ореол. В темноте она не тускнеет.
- За ней тянется светящаяся радужная лента длиной около секунды полёта: сужается к концу, гаснет, и цвета бегут вдоль неё. Позади ленты ещё немного висят разноцветные блёстки.
- Над текущей целью кружатся две красные искры, так что видно, за кем стрела гонится.
- Запуск, удар и падение сопровождаются вспышкой разноцветных искр, победа над мобом — фейерверком и звонким «дзынь».
- В полёте стрела тихо свистит; на скорости свист громче и выше.

## Управление

| Действие | Клавиша |
|---|---|
| Выпустить стрелу | ПКМ с предметом в руке |
| Сменить режим | `R` |
| Указать цель (моб под прицелом) | `V` |
| Свистнуть и отозвать стрелу | `G` |

Клавиши переназначаются в «Настройки → Управление → Стрела Олегуса». Если при запуске в режиме «Выбранная цель» под прицелом нет моба, стрела кружит рядом и ждёт, пока вы укажете цель клавишей `V`. В режиме «Все мобы» `V` задаёт цель, которую стрела атакует первой.

## Как получить

- Творческий режим: вкладка с боевыми предметами.
- Команда: `/give @s olegus_arrow:olegus_arrow`.
- Крафт:

  ```
   .  Аметист  .
  Редстоун Стрела Редстоун
   .  Алмаз  .
  ```

## Установка для одиночной игры

1. Установите [Fabric Loader](https://fabricmc.net/use/) 0.16+ для Minecraft 1.21.1.
2. Скачайте [Fabric API](https://modrinth.com/mod/fabric-api/versions?g=1.21.1) для 1.21.1.
3. Положите `fabric-api-….jar` и `olegus-arrow-1.0.0.jar` в папку `.minecraft/mods`.
4. Запустите игру с профилем Fabric и создайте или откройте мир.

Для одиночной игры больше ничего не нужно: встроенный сервер одиночного мира работает из того же jar. Для игры на чужом сервере мод должен стоять и на нём.

## Сборка и проверка

Нужен JDK 21.

```bash
./gradlew build        # мод появится в build/libs/olegus-arrow-1.0.0.jar
./gradlew runClient    # запустить игру с модом
./gradlew runGametest  # игровые тесты на сервере
```

Игровые тесты лежат отдельно (`src/gametest`) и в jar мода не попадают. Они проверяют, что стрела убивает всех мобов в режиме «Все мобы» — и в открытом поле, и когда часть мобов за стеной; в режиме «Выбранная цель» не трогает остальных и достаёт цель за стеной до земли; возвращается в инвентарь по свисту; падает предметом без владельца; не выбирает целью игроков и питомцев; находит путь вокруг стены и ускоряется не больше чем вдвое. Каждый тест идёт на своей пустой арене 24×12×24 (`tools/generate_test_arena.py`). GitHub Actions на каждый push собирает мод, выкладывает jar в артефакты запуска и прогоняет тесты.

## Демо-ролик

`tools/demo/record.sh` записывает ролик с модом: запускает настоящий клиент Minecraft на виртуальном экране (Xvfb, программный OpenGL), сценарий из `src/demo` сам создаёт плоский мир, расставляет мобов и играет — целится, выпускает стрелу, жмёт клавиши режима и свиста. Подписи вверху экрана объясняют, что происходит. Нужны Linux, xvfb, pulseaudio и ffmpeg. GitHub Actions (`.github/workflows/demo.yml`) записывает ролик на каждый push и кладёт его в артефакты запуска. Сам сценарий в jar мода не попадает.

## Настройка

Все числа вынесены в константы:

- `entity/OlegusArrowEntity.java` — время жизни, момент колокольчика, скорость, урон, поворотливость, радиусы кружения;
- `entity/TargetRules.java` — что считать толпой и насколько разгоняться.

Текстуры (иконка предмета, модель, свечение, лента следа), иконку мода и звуки (свист, ответ стрелы, взлёт, свист в полёте) генерирует `tools/generate_assets.py`; для него нужны Pillow, numpy и ffmpeg с libvorbis.

## Устройство

```
src/main/java/com/olegus/arrow/
  OlegusArrowMod.java          — точка входа
  ArrowControl.java            — серверная логика клавиш: режим, цель, свист
  ArrowMode.java               — режимы стрелы
  entity/OlegusArrowEntity.java — полёт, атака, таймер, возврат, история следа, маркер цели
  entity/ArrowPathfinder.java  — поиск пути в обход препятствий
  entity/TargetRules.java      — выбор целей и ускорение в толпе
  item/OlegusArrowItem.java    — предмет
  network/                     — пакеты клиент ↔ сервер
  registry/                    — регистрация предмета, сущности, звуков, урона и режима игрока
src/client/java/com/olegus/arrow/client/
  ArrowKeyBindings.java        — клавиши
  ArrowHud.java                — надпись и полоска времени над здоровьем
  OlegusArrowRenderer.java     — модель, свечение и лента следа
  ArrowFlightSound.java        — свист стрелы в полёте
src/gametest/                  — игровые тесты
src/demo/                      — сценарий демо-ролика
```
